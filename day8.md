## Theory & Classroom Explanation

### 1. Python Comprehensions
Comprehensions provide a compact syntax for generating new collections from existing iterables:

```python
# Traditional Loop
squares = []
for x in range(10):
    if x % 2 == 0:
        squares.append(x**2)

# List Comprehension equivalent
squares = [x**2 for x in range(10) if x % 2 == 0]
```

### 2. Why `.gitignore` is Essential
Without `.gitignore`, dynamic temporary files generated by Python interpreters (`__pycache__`), virtual environment folders (`.venv/`), and IDE configurations (`.vscode/`) pollute remote repositories. `.gitignore` tells Git which files to ignore completely.

## Practical Coding Exercises

### Exercise 8.1: Memory Benchmarking & Comprehensions
Create `day8_comprehensions.py`:

```python
# Day 8: Comprehensions & Sequence Performance Benchmarking
import sys
import time

# Preserving memory/time benchmark from existing Day_Two.ipynb material
sample_size = 1_000_000
print(f"Benchmarking sequence creation for {sample_size:,} elements...")

# Memory allocation test
list_data = list(range(sample_size))
tuple_data = tuple(range(sample_size))

list_mem = sys.getsizeof(list_data)
tuple_mem = sys.getsizeof(tuple_data)

print(f"List Memory Allocation : {list_mem:,} bytes")
print(f"Tuple Memory Allocation: {tuple_mem:,} bytes")
print(f"Memory Saved by Tuple  : {((list_mem - tuple_mem) / list_mem) * 100:.2f}%")

# List Comprehensions
words = ["apple", "banana", "cherry", "date"]
upper_words = [w.upper() for w in words]
filtered_words = [w for w in words if len(w) > 4]

# Dictionary Comprehension
word_length_dict = {w: len(w) for w in words}

print("\nUpper Words:", upper_words)
print("Filtered Words (> 4 chars):", filtered_words)
print("Word Length Dictionary:", word_length_dict)
```
